PCG ANNOUNCEMENTS — ASSET STRUCTURE

All website images are now stored in:
assets/images/

Images have been resized/compressed to WebP for faster loading.

To add the requested new announcement image:
1. Save the image as:
   assets/images/new-announcement.webp
2. Open index.html.
3. In the NEW ANNOUNCEMENT IMAGE section, change:
   data-ready="false"
   to:
   data-ready="true"
4. Edit the heading/text in that announcement if needed.

The new announcement slot is positioned immediately after the Sunday Service slide.
